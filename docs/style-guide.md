# 翻訳スタイルガイド

公式日本語訳（本編・Space Academy）の書き方に合わせる。迷ったら公式訳の同種テキストを優先する。

※ このガイドの「公式訳の例」と用語の表にある訳は、Two Point Campus の公式日本語訳（©SEGA）からの引用です。

## 1. 文体（テキストの種類別）

| 種類 | 文体 | 公式訳の例 |
|---|---|---|
| アドバイザー・チャレンジ・レベル導入 | です・ます調。最後の文は「。」を付けないことが多い | 学生たちが最初の授業を終えました。…集中できます |
| 部屋・研究・設備の説明 | だ・である調／「～しよう」 | …しっかりと財宝を守ろう |
| アイテム名・部屋名・ステータス名 | 名詞。体言止め | 顕微鏡、研修室、もう我慢できない |
| ボタン・ラベル | 短い名詞句／「～を○○」 | アイテムを削除、プロジェクトのキャンセル |
| 実績・サブゴール | 「～する」「～を獲得」 | 100台の機械をアップグレードする |
| 構内放送（Tannoy） | `<style="Tannoy">構内放送：…</style>`。丁寧語 | 構内放送：ガジェット・ラボに用務員が必要です |
| ラジオ（Radio） | `話者名：…`。話者ごとの口調を維持 | ハリソン：…、ナイジェル：… |
| キャラクターのセリフ | 人物像に合わせる（ジャンボ＝尊大、ナイジェル＝皮肉屋 など） | |
| 学生の個人目標・独白 | くだけた話し言葉 | パーティーには行きたいけど… |

- 1つの訳文が複数文になる場合、文中は「。」で区切り、末尾の「。」は原文が説明文でも付けない（公式訳の傾向）。疑問・感嘆は「？」「！」を残す。
- 英語の改行（`\n`）と `<br>` は位置を保つ。

## 2. 記号

- 句読点・括弧は全角：「、」「。」「！」「？」「：」「（）」「「」」『』。ただし `{NAME}({COURSE})` のようにパラメータを囲む括弧は公式訳どおり半角。
- 三点リーダーは「…」（1文字）。英語の "..." も「…」にする。
- 作品名・番組名は『』、セリフ・引用・名称の強調は「」。
- 数字は半角。単位は日本語（3倍、50人、10万）。

## 3. 必ず保持するもの（QAで自動チェック）

- パラメータ：`{COUNT}` `{ROOM}` `{NAME}` `{0}` など（語順は日本語に合わせて移動してよい）
- タグ：`<style="…">…</style>` `<sprite=…>` `<color=…>…</color>` `<br>`
- 複数形タグ `[i2p_One]`：日本語は単複同形なので、前後に同じ訳文を入れる（例：`学生が卒業する[i2p_One]学生が卒業する`）

## 4. 固有名詞・用語

- 既存の用語は公式訳に合わせる（`work/glossary_official.tsv`。`tools/worklist.py` が手元のゲームのデータから作る公式用語集で、リポジトリには含まない）。主な例：

| 英語 | 公式訳 |
|---|---|
| Kudosh | 勲章ポイント |
| Two Point County | ツーポイント州 |
| Janitor / Assistant / Teacher | 用務員 / アシスタント / 教員 |
| Campus | 大学（文脈により「キャンパス」） |
| PA System（Tannoy） | 構内放送 |
| Medical Office（保健室系） | 医務室 |
| Pastoral Care | 心のケア |

- 新出の固有名詞（DLCの病名・機械・部屋・人物など）は、先に名前だけをまとめて訳し `translations/glossary_new.tsv` に登録してから本文を訳す。
- 人名：普通の名前はカタカナ。ダジャレ・意味のある名前（Flub、Raspy、Shoeblack など）は、公式訳と同じく意味を生かした日本語名（ヘタウチ、ミミザワリ、クツキレイ）にしてよい。
- ダジャレ・言葉遊びは直訳より「日本語として笑える」ことを優先する。意味が大きく変わる場合は note に原意を残す。

## 5. その他

- 公式訳にある文字以外の漢字も使えるが、静的フォント（2,025字）に無い字は QA が一覧表示する。常用漢字の範囲を目安にし、難読字は避ける。
- 未使用と思われる項目（"Unused"、"(PH)" など）は訳さない。
