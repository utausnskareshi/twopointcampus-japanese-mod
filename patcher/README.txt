Two Point Campus 日本語化パッチ　バージョン {VERSION}

■ これは何？
Steam版「Two Point Campus」には公式の日本語訳が入っていますが、ゲームの言語設定に「日本語」が出てこないうえ、
DLC（メディカルスクール、スクールスピリッツ）やチャレンジモード、MOD画面など約2,400項目が英語のままです。
このツールは次の2つを行います。

  1. 英語のままの項目に日本語訳を補う（公式訳がある項目は一切変更しません）
  2. ゲームの表示言語を日本語に切り替える

■ 動作環境
・Windows 10 / 11（.NET Framework 4.8 を使います。Windows に標準で入っています）
・Steam版 Two Point Campus（動作を確認したバージョン：{GAME_VERSION}）

■ 使い方
  1. ゲームを一度起動してタイトル画面まで進め、終了します（初回のみ。言語の設定ファイルを作るためです）。
  2. ZIP を好きなフォルダーに展開し、TpcJpPatch.exe を実行します（インストールは不要です）。
  3. 起動すると Steam からゲームのフォルダーを自動で探して表示します。
     Steam版がインストールされていない場合は、その旨を表示して終了します。
  4. 「日本語化する」を押します。完了のメッセージが出たら、ゲームを起動してください。

  ※ ゲームの起動中は実行できません。
  ※ Windows の SmartScreen の警告が出た場合は「詳細情報」→「実行」で起動できます。

■ 元に戻す
TpcJpPatch.exe の「元に戻す」を押すと、公式の日本語データに戻し、表示言語を以前の言語（通常は英語）に戻します。
日本語データやバックアップの状態を確認できないときは、何も変更せずにバックアップを残し、メッセージでお知らせします。
ツールが使えないときは、Steam のライブラリで Two Point Campus を右クリック →「プロパティ」→「インストール済みファイル」→
「ゲームファイルの整合性を確認」でも公式のデータに戻ります（この場合、表示言語は日本語のままです）。

■ ゲームのアップデート後
アップデートや「ゲームファイルの整合性を確認」で日本語データが公式のものに戻ると、このパッチの訳が消えて英語の項目が戻ります。
もう一度「日本語化する」を押してください。アップデートで公式訳が追加された項目は、公式訳が優先されます。

■ 注意・既知の制限
・ゲームの設定画面の「言語」欄は「トルコ語（Türkçe）」と表示されますが、日本語で動作しています。
  この欄で言語を選び直すとその言語に切り替わります。日本語に戻すには、もう一度「日本語化する」を押してください。
・Steam でこのゲームの言語設定を変更すると、ゲームの表示言語がその言語に戻ります。
  日本語に戻すには、もう一度「日本語化する」を押してください。
・音声（構内放送やラジオ）は英語のままです。字幕が日本語になります。
・タイトル画面右上のお知らせ（DLC の紹介など）は、サーバーから配信される英語の文章なので日本語になりません。
・別のPCで遊ぶ場合は、そのPCでもこのツールを実行してください（日本語データの書き換えはPCごとに必要です）。
・このパッチの訳は有志による非公式のものです。公式の日本語訳と言い回しが異なる場合があります。

■ このツールが変更するファイル
・日本語データ
    <ゲームのフォルダー>\TPC_Data\StreamingAssets\aa\StandaloneWindows64\localisation_assets_localisationjapanese.bundle
    適用前の公式データを同じ場所に「～.bundle.tpcjp-original」として保存し、状態を「～.bundle.tpcjp-state」に記録します。
    「元に戻す」で公式のデータに戻したことを確認した後、この2つのファイルは削除されます。
・表示言語の設定
    %USERPROFILE%\AppData\LocalLow\Two Point Studios\Two Point Campus\Cloud\<SteamのID>\preferences.json
    変更前の内容を %LOCALAPPDATA%\TpcJpPatch\backup に保存します。
・ログ：%LOCALAPPDATA%\TpcJpPatch\TpcJpPatch.log

■ コマンドラインでの使い方（上級者向け）
  TpcJpPatch.exe status                       状態を表示
  TpcJpPatch.exe apply [--no-language]        日本語化（--no-language：表示言語は変えない）
  TpcJpPatch.exe restore [--keep-language]    元に戻す（--keep-language：表示言語は変えない）
  TpcJpPatch.exe language ja|en|previous      表示言語だけを切り替える（previous：日本語化する前の言語）
  status / apply / restore のオプション：--game <ゲームのフォルダー>
  終了コード：0 成功、1 エラー（表示言語の切り替えの失敗を含む）、2 コマンドやオプションの誤り
